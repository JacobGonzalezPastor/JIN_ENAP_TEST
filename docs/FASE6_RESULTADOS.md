# Fase 6 — Resultados JIE26

1. No modificar `Competencias`.
2. Registrar resultados desde la Dashboard.
3. Crear documentos en `Resultados`.
4. Mantener modo de prueba local para validar formularios sin escribir Firebase.

6. La escritura en Firebase requiere un usuario que exista en `Administradores` con `activo: true`, según `firestore.rules`.
7. No borrar las colecciones legacy durante esta fase.
