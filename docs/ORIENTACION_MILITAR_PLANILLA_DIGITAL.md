# Orientación Militar — ajuste de planilla digital

Cambios en la planilla de registro:
- Dorsal editable manualmente.
- Se agregan Género, Posición, Puntos y Observaciones.
- Se eliminan Hora de salida, Hora de llegada y Penalización.
- Los errores de tiro y baliza se consolidan en un campo numérico de total de errores.
- El estado queda limitado a FINAL o DESCALIFICADO.
- Se conservan Tiempo bruto y Tiempo definitivo.
- Los participantes marcados DESCALIFICADO no se incluyen en la clasificación/medallería derivada.

La columna de errores registra un total único; no se aplica una conversión automática a tiempo de penalización porque no se proporcionó una regla oficial para esa conversión.
