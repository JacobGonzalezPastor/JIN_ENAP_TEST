# Medallero JIN-ENAP 2026 — prioridad estricta y puntaje informativo

El medallero se ordena por cantidad de oros, luego platas y luego bronces. El puntaje ponderado (oro=1000, plata=100, bronce=1) se muestra como información complementaria y no afecta el puesto.

Ejemplo: Escuela A (1 oro, 0 platas, 0 bronces) queda por encima de Escuela B (0 oros, 100 platas, 0 bronces), aunque B tenga 10.000 puntos ponderados.
