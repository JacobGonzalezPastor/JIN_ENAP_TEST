# Ajuste visual del formulario de tenis

- Se agruparon los campos por Pareja A y Pareja B.
- Escuela y jugadores quedan dentro de tarjetas separadas y responsivas.
- Los campos de segundo jugador aparecen solo para dobles y dobles mixtos.
- Los sets se presentan en bloques compactos y las estadísticas en una sección propia.
- Se conservaron los IDs de los controles para mantener la lógica de guardado, edición y Firebase.
- Los estilos nuevos usan clases `tennis-*` para evitar afectar otras disciplinas.

Validación realizada: sintaxis JavaScript, integridad ZIP y presencia de IDs de controles existentes. No sustituye una prueba interactiva en navegador ni una prueba real de Firebase.
